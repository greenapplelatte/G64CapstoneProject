# SDPBUS / Waypoint Shuttle Management System

An offline desktop application for tracking, updating, and auto-filling daily bus and shuttle trips.

## Setup Instructions
1. Ensure PHP (with `pdo_sqlite` enabled) and a web server (or PHP Built-in Server / PHP Desktop) are installed.
2. Place the project directory inside your local server folder.
3. Start the application by navigating to `index.php`.
4. The SQLite database (`waypoint.sqlite`) will automatically initialize on first load inside the `database/` folder.
